# iOS backend

Будущий backend реализует семантику из `contract/model.json` и использует
сгенерированные типы `contract/generated/VisorContract.swift`. Выбор
AVFoundation, CoreMotion, Metal и способа транспорта принадлежит платформе.
Рабочая реализация iOS и проект Xcode в текущей ветке ещё не добавлены.
