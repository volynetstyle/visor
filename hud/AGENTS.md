# Обязательные инварианты интерфейса

Перед изменением HUD прочитай [PERFORMANCE.md](../docs/PERFORMANCE.md).

- Общий контракт находится в `contract/` над core и платформами. Core
  задаёт семантику и HUD, physical backend управляет устройством. OS-проверки и
  Native transport допускаются только в `platforms/android/web/platform.js`, не в runtime/HUD.
- Сохраняй один ожидающий rAF и только последнее состояние. Простой не запускает
  циклы, таймеры или polling; скрытый документ не рендерит и не отправляет жесты.
- Одинаковое состояние даёт ноль DOM-записей. Обновляй только изменившиеся поля;
  сохраняй ARIA-состояния и прозрачность корневого фона.
- Не читай геометрию DOM в render, touch и animation callbacks. Размер viewport
  кэшируется при загрузке/resize. Анимируй только transform/opacity.
- Объединяй pinch-события в один вызов Kotlin за кадр, сохраняя накопленный
  множитель, включая последний перед отпусканием. Не задерживай команды затвора.
- Запрещены runtime-зависимости, внешние ресурсы, JS-обработка изображений,
  сетевые вызовы и постоянные GPU-слои через will-change.
- Выполняй `powershell -NoProfile -ExecutionPolicy Bypass -File tools/web-check.ps1`
  из корня проекта. Проверки также обязательны для Android preBuild.
- Не увеличивай бюджеты и не ослабляй тесты ради прохождения проверки. Изменение
  контракта обосновывается замерами на целевом устройстве и документируется вместе
  с изменением поведения.
- Меняй canonical definition и перегенерируй bindings вместо ручных правок
  Kotlin/Swift/TypeScript-копий. Ответы RPC и terminal capture events нельзя
  объединять как телеметрию. Сохраняй session/identity/cancellation barriers.
- Одноразовые deadlines разрешены только для ограниченных RPC, снимаются при
  завершении/dispose; polling и повторяющиеся таймеры запрещены.
